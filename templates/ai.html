接入 AI 大模型（3 分钟搞定）
本系统兼容所有 OpenAI 格式的大模型接口。选择一家服务商，注册获取 API Key， 填入项目根目录的 .env 文件，保存后重启即可对话。
DeepSeek（推荐） 阿里云百炼（通义） 本地 Ollama（免费）
  1. 打开 platform.deepseek.com，注册并登录。
  2. 进入「API Keys」页面，点击「创建 API Key」，复制得到的密钥（形如 sk-xxxxxx）。
  3. 在「充值」页面充值少量金额（DeepSeek 按用量计费，很便宜）。
  4. 打开项目根目录的 .env 文件，填入以下三项：
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-把你的密钥粘贴到这里
  1. 打开 阿里云百炼控制台，用阿里云账号登录。
  2. 在「API-KEY」页面创建密钥并复制（形如 sk-xxxxxx）。
  3. 开通「通义千问」模型服务（新用户通常有免费额度）。
  4. 打开项目根目录的 .env 文件，填入以下三项：
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-plus
LLM_API_KEY=sk-把你的密钥粘贴到这里

提示：图片解析技能使用通义千问多模态模型，建议模型填 qwen-vl-plus 或另配阿里云 Key。

  1. 打开 ollama.com/download 下载并安装 Ollama。
  2. 打开命令行运行 ollama pull qwen2.5 下载模型（完全免费、本地运行、数据不外传）。
  3. 确保 Ollama 正在运行（默认端口 11434）。
  4. 打开项目根目录的 .env 文件，填入以下三项：
LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=qwen2.5
LLM_API_KEY=ollama

本地模型无需付费，但速度取决于你的电脑配置。

填写完成后，保存 .env 文件并重新运行 start.bat（或重启服务），即可开始对话。
